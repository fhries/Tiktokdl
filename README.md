# VibeTik Downloader

**VibeTik Downloader** adalah website sederhana dan modern untuk mengunduh video TikTok dengan mudah.

---

## ✨ Fitur

- 🎥 Mengunduh video TikTok
- ⚡ Proses cepat dan sederhana
- 🎨 Mendukung tema **Light** dan **Dark**
- 📱 Tampilan *responsive* dan *mobile-friendly*
- 🖥️ Bisa digunakan melalui browser
- 🎚️ Pilihan kualitas video
- 🔗 Cukup masukkan link video TikTok

---

## 🚀 Cara Menggunakan

1. Buka website **VibeTik Downloader**.
2. Salin link video TikTok yang ingin diunduh.
3. Tempel link tersebut pada kolom yang tersedia.
4. Pilih kualitas video.
5. Tekan tombol **download**.
6. Tunggu proses selesai, lalu simpan video.
