# VibeTik Next.js 15

Full-stack TikTok downloader menggunakan Next.js 15 App Router, React 19, TypeScript, dan scraper VibeTik sebagai backend internal.

## Jalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

Scraper berada di `lib/vibetik.ts` dan tidak diekspos langsung ke client.

> Pastikan penggunaan downloader mematuhi aturan platform, hak cipta, dan ketentuan layanan sumber video.
